## 📂 Cấu trúc thư mục
- `index.html`: Trang chủ (Giới thiệu bản thân, mục tiêu, thành tích).
- `projects.html`: Danh sách các dự án thực tiễn và bài tập.
- `summary.html`: Tổng kết quá trình học tập và trải nghiệm.
- `bai1.html` - `bai6.html`: Các trang chi tiết cho 6 bài tập thực hành môn học.
- `css/`: Chứa các file style (bao gồm hệ thống thiết kế riêng).
- `js/`: Các file mã script xử lý hiệu ứng và tương tác.
- `assets/`: Thư mục chứa hình ảnh và các tài nguyên tĩnh khác.
